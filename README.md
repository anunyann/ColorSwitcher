# 🎮 Color Switcher (Unity 2D)

A browser-playable color-matching game built in Unity WebGL.

🚪 Match your player’s color with the gate — get it wrong and it's game over!

## 🕹️ Controls
- Move: `A / D` or `← / →`
- Change color: `Spacebar`

## 🌐 Play Online
👉 [Play the game on itch.io](https://anunyan.itch.io/color-switcher)

## 💻 Built With
- Unity 2023 (WebGL)
- C#
